# 세턴쿠지 V9 LEGENDARY PREMIUM GAME UI

V8의 캡슐 분리/3D 상품 카드 기반으로 S급 전용 시네마틱 연출을 강화했습니다.

## V9 S급 연출
1. **화면 전체 암전** — 결과 직전 전체 화면이 블랙으로 잠깐 전환
2. **금빛 플래시** — S급 순간 화면 전체를 강한 골드 라이트가 덮음
3. **캡슐 파편 돌출** — 캡슐이 깨지며 붉은 파편이 카메라 앞으로 빠르게 날아오는 원근감 연출
4. **상품 대형 확대** — 실제 등록 상품 이미지가 중앙에서 크게 확대되며 등장
5. **S LEGENDARY 홀로그램** — 카드 위에 스캔라인/프레임/문구가 겹쳐져 레전더리 등급을 강조
6. **금색 파티클 + 진동 + 효과음** — S급 전용 피드백

### 결과 타임라인
- 0ms: 전체 암전
- 180ms: 금빛 플래시
- 360ms: 캡슐 파편 폭발
- 860ms: 상품 카드 대형 등장/줌 아웃
- 이후: S LEGENDARY 홀로그램 + 파티클

## 기능 유지
- Home / Draw / Collection / Admin 고정 하단 탭
- 1/3/5/10회 뽑기
- S/A/B/C/D 희귀도
- 001~100 상품 관리
- 실제 상품 이미지 등록
- 자동 저장 / 직전 뽑기 취소 / 전체 리셋
- S급 외 등급은 빠른 프리미엄 결과 연출

## 상품 이미지
Admin → 상품 카드 → 상품 사진 등록/변경에서 실제 상품 사진을 연결하면 V9 결과 카드에 표시됩니다.
